# plex-renamer — Agent operating guidance

This file is the policy committed to the repo and visible inside every worktree. It is what code review profiles, the AC validator, and the primary agent see as authoritative repo policy.

## Test command

```
uv run pytest
```

For GUI tests in headless mode (required for autonomous runs):

```
QT_QPA_PLATFORM=offscreen uv run pytest tests/test_gui*.py
```

## Lint command

```
uv run ruff check .
uv run ruff format --check .
```

To auto-fix:

```
make tidy
```

## Combined gate

```
make check && make test
```

## Python baseline

Python 3.13 is the floor. `pyproject.toml` declares `requires-python = ">=3.13"`. CI runs on the 3.13 ubuntu-latest / macos-latest / windows-latest matrix.

## Off-limits paths

- **`/Volumes/Cage/Media/CleverGet`** is READ-ONLY. It is a reference media tree used to inform the parser test corpus. No code path in this repo may write to, move, rename, or delete anything under that prefix. A `tests/conftest.py` autouse fixture (landing in slice 2) monkeypatches the writable filesystem surface to raise `RuntimeError` if any test crosses this boundary. CI fails if any test triggers the guard.
- `.env` is gitignored and contains the user's TMDB API key. Never commit it; never echo its contents into logs or test output.

## Engine / GUI separation

The code base is split into three layers:

1. **Engine** under `src/plex_renamer/{parser,tmdb,planner,executor}/`. Pure logic, no Qt imports. Testable from the CLI.
2. **CLI** under `src/plex_renamer/cli/`. Thin Typer wrapper over the engine. Exposes `plan`, `apply`, `undo`.
3. **GUI** under `src/plex_renamer/gui/`. PySide6 thin client over the engine. Imports the engine; the engine NEVER imports the GUI.

Slice boundaries follow this split. Don't reach across them.

## Commit style

Conventional commits. Lowercase after the prefix. Imperative mood. See `~/.claude/CLAUDE.md` for the user's full preferences.

## Branch naming

`ryan/<slug>`. No `feat-` / `fix-` prefix on slugs. 2-5 lowercase hyphen-separated words.

## Plex naming the app emits (canonical)

- Movies: `<library>/Movie Name (Year) {tmdb-X}/Movie Name (Year) {tmdb-X}.ext`
- TV: `<library>/Show Name (Year) {tmdb-X}/Season 0N/Show Name (Year) - S0NE0M - Title.ext`

When TMDB has no confident match, the anchor becomes `{imdb-ttX}`. The folder always carries the anchor; episode files do not.
