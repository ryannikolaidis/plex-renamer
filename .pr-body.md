## Why It Matters

The Windows shell shipped with three structural UX problems that compounded into a "cluttered" feel:

1. **Every per-row action lived inside a 640×680 modal** triggered only by double-click. No right-click, no multi-select, no "Reveal in Explorer" or "Copy path", no keyboard. The user couldn't act on rows in any quick, native way.
2. **The bottom-left strip duplicated Settings** — two labels, two ellipsized paths, two "Change…" buttons for the library roots, permanently visible even though the value never changes mid-session.
3. **`ConfidenceBadge` existed as a UserControl but was never bound anywhere**, so the user had no in-list signal of parse quality and had to open the modal per row to find out.

Apply behaviour also had two real bugs: the button was always enabled (you could click Apply on an empty state), and `CollisionReviewDialog` claimed a choice the UI didn't offer (the primary button skipped every colliding source — no per-collision picker).

## Summary

This PR is the WPF UX cleanup pass. Per-row actions move into a native right-click `ContextMenu` with multi-select Skip and an "Override metadata" submenu, the inline library-roots strip is replaced with a one-line `StatusFooter` (with engine state + indeterminate spinner on the right), and Settings becomes a title-bar gear icon. The `CollisionReviewDialog` becomes a real per-collision picker, the `SettingsDialog` gets sectioned, and `ConfidenceBadge` gets wired into both panel row templates with a "NO ANCHOR" placeholder when no candidate is resolved. Keyboard shortcuts (Ctrl+,, Ctrl+P, Ctrl+Enter) land. macOS Qt path is untouched.

## Changes

**Row interactions** (`SourcePanel.xaml` + `.cs`, `TargetPanel.xaml` + `.cs`):
- ListBox `SelectionMode="Extended"` on the source panel.
- Right-click `ContextMenu`: Edit row · Search TMDB · Set IMDb ID · Pick show (TV unanchored only) · Override metadata (Title / Year / Season / Episode / Edition) · Skip · Reveal source in Explorer · Copy source path.
- Multi-select propagates to Skip and Override-metadata.
- Empty-state placeholder text in both panels.
- Header text shows file count + skipped count once content is loaded.
- New `SingleValuePrompt` modal hosts per-field overrides — single field, IsDefault / IsCancel, no scrolling.

**ConfidenceBadge** (`Views/Converters/RowConverters.cs` + row templates):
- Bound into both panels' row templates. Green / yellow / red per `INVARIANTS.md` confidence bands.
- Grey "NO ANCHOR" placeholder for rows without a Candidate.
- `SkipToOpacityConverter` dims skipped rows so the user can see Skip state at a glance.

**Settings as a title-bar gear**:
- `ActionBar` reduces to Preview + Apply.
- `MainWindow` `ui:TitleBar.TrailingContent` carries a Settings gear button.
- `Apply` button enables only when files are loaded, library roots are set, the engine is live, and at least one row isn't Skip. Tooltip surfaces the missing precondition.
- Keyboard shortcuts via `InputBindings`: `Ctrl+,` Settings · `Ctrl+P` Preview · `Ctrl+Enter` Apply.

**StatusFooter** (`Views/StatusFooter.xaml` + `.cs`):
- Replaces the deleted `LibraryRootsInline`. One-line footer below the action bar.
- Left: clickable library-root status (`Movies → …\Movies · TV → …\TV`) that opens Settings on click. Tooltip shows the full path. Falls back to "Set library roots in Settings →" when unset.
- Right: engine state (Stopped / Ready / Busy / Disconnected) with an indeterminate `ui:ProgressRing` while a long-running engine call is in flight.

**`RunReport` becomes an `InfoBar`**:
- Apply success/failure surfaces as a Fluent `ui:InfoBar` with a Close button.
- The legacy `RunReport` widget stays as a detail surface for the error list + Undo button when there's something to act on. Clean runs only show the InfoBar.

**`SettingsDialog` reorg**:
- Sections (TMDB / OMDB integration · Library roots · Apply behaviour) with H6-equivalent headers.
- Library-root rows get inline `Browse…` buttons.
- Cleanup checkbox gated behind a Warning InfoBar that explains what cleanup actually deletes.
- TMDB instructions are a proper `Hyperlink` with `RequestNavigate`.
- Width bumped from 520 to 640, IsDefault on Save, IsCancel on Cancel, AutomationProperties.Name on every interactive control.

**`CollisionReviewDialog` real winner picker**:
- Each collision shows the colliding sources as a `RadioButton` group; the user picks one winner per collision. Non-winners get marked as Skip in the next preview.
- "Skip all colliding sources" remains as an escape-hatch button.
- Headline shows the count: `N collisions affecting M sources`.

**`EditPane` polish**:
- Row identity (filename + full path) promoted to the dialog header above the scroll viewer.
- `Skip` checkbox raised to the top so it's visible without scrolling.
- TMDB results list grows from 120px to 200px.
- Manual overrides grouped under Title/Year · Season/Episode · Edition sub-headers.
- Save / Cancel get IsDefault / IsCancel.

**`DropZone` polish**:
- Border flips to a Fluent accent colour on drag-over.
- New `Browse…` button gives keyboard-only users a path past the empty state.
- `SetLoadedState(int fileCount)` collapses the headline to a thin "N files loaded · drop more to append" caption once content is loaded.

**`TmdbKeyPrompt`**:
- "themoviedb.org → Profile → Settings → API" becomes a real Hyperlink.
- Added a Skip-button explanation so the user understands what happens.

**`CleanupConfirmModal`**:
- Emoji `⚠` warning replaced with `ui:SymbolIcon Symbol="Warning24"` for consistency with Fluent chrome.
- Path list gains per-row ToolTip so truncated long paths can be hovered to see the full value.

**Accessibility**:
- `AutomationProperties.Name` on every interactive control in the affected views.
- HelpText where the default name isn't self-describing (Browse, drop zone, list boxes).

**Tests**:
- `ResolveTimeRenderingTests` replaces the `LibraryRootsInline` rendering test with the `StatusFooter` equivalent (same Measure+Arrange + ActualWidth/Height assertion).
- `LibraryRootsInlineTests` deleted with the control it covered.
